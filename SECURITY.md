# Security

Do not report vulnerabilities using public issues when they include secrets,
private data, or exploit details.

For v0.1, open a private security advisory or contact the maintainers through
the repository owner profile. Include the affected command, expected behavior,
actual behavior, and a minimal reproduction that uses synthetic data.

This repository must not contain live credentials, private contacts, private
memory, real message bodies, production calendar data, or private source Git
history. Run `./scripts/preflight.sh` before pushing changes.
